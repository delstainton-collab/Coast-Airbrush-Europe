# Coast Airbrush Europe

> **The Official European Hub for Custom Automotive Paint, Airbrush Systems, Kroma Edge & Flake King**

## Overview
Coast Airbrush Europe is the dedicated European e-commerce storefront, mixing engine, CRM platform, and technical hub for custom automotive painters, airbrush artists, and motorcycle builders across Europe and the UK.

### Key Features
- **Interactive Paint Mixing Engine**: Real-time volume, reduction ratio, and multi-stage formula calculator.
- **Kroma Edge & Master Series Catalog**: Complete technical specs, safety compliance (ADR / VOC), and dynamic pricing.
- **Shopify & E-Commerce Integration**: Multi-currency checkout (EUR, GBP, USD), localized tax/duty calculation, and live cart sync.
- **AI Specialist Agent Suite**:
  - **Agent A (Master Painter)**: Technical sales and application advice.
  - **Agent B (Order Concierge)**: Autonomous order tracking and logistics updates.
  - **Agent C (Kustom Marketer)**: Social media and community growth automation.
  - **Agent D (Stock Guru)**: Lean inventory forecasting across UK & Netherlands bonded warehouses.
